## Math Formulas

- n-th Triangular Number
  This formula is a specific case of the "Arithmetic Progression Sum Formula". It is used to calculate the sum of the first n consecutive natural numbers.
  Imagine your number (n) as a triangle made up of dots. The base is n dots wide, and each level above it has one fewer dot.
  This pattern continues until you reach the top: a single dot.
  Now, convert that triangle into a right triangle, then double it in size to create a rectangle.
  The width of said rectangle is equal to n, while the height is equal to n + 1.
  We can reverse this logic to create the mathematical formula show in the next line
  Tn = (n(n + 1)) / 2
  "T" stand for triangular, "n" for the position of the number in the sequence. Together they mean "the n-th triangular number".
